# AGENTS.md

## Language

- Write everything in this repository in English: code, identifiers, comments,
  documentation and commit messages.

## Git conventions

- Use Conventional Commits for commit messages. Avoid long descriptions in
  commit bodies, unless necessary.

## Working on issues

- Before starting an issue, check its assignees. If the user you are assisting
  is not assigned to the issue, ask that user for confirmation before
  proceeding. If the issue is unassigned, proceed and tell the user it was
  unassigned.
- Ask for clarification when a product decision is missing.
- Work on a branch and keep changes focused on the issue.
- Add or update tests when behavior changes. Run the relevant checks and
  `just check` before opening a pull request; report any checks that could not
  pass.
- Open a pull request against `main`. Follow the repository's pull request
  template, link the issue, and identify any unfinished acceptance criteria.
- Leave the pull request for human review; do not merge it.
